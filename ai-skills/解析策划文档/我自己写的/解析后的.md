功能
- 任务系统
	- 任务类型分为试玩、高额、视频
	- 完成任务获得积分 + 小额奖励
	- 每天完成一定任务次数，增加一次抽奖次数，减少对方积分
- 机器人系统
	- 机器人没有自动执行的逻辑，都随着玩家每次请求触发
	- 策划需求：机器人每天在固定的时间连续完成任务
		- 这个只是策划的逻辑
		- 从程序看固定时间完成，和玩家每次请求后触发判定机器人应该做哪些处理。最后对于玩家来说表现没有区别
		- 对于玩家来说，看到是一样的
	- 结算时刻前机器人在min（1小时，周期剩余时间）内随机一个时间点放弃
- 转盘奖励
	- 积分卡

- 积分卡
	- 每日使用有上限
	- 有有效期

- 弹幕逻辑
	- 发生一些事件(示例：扔炸弹等等..)，需要播放弹幕


- 一段时间未登录，获得积分
- 当大于对方积分那一刻，获得积分 + 发留言
	- 留言内容在指定配置中随机一句
	- 用户收到留言界面后，清空全部未读留言

- 最后一天，积分 = 积分 * (1 + 系数)
	- （（默认积分*ecpm加成）+唤醒额外积分）*决战时刻翻倍
- 最后发奖逻辑
	- 超过一个配置价值，随机奖励
	- 根据用户产生价值/配置价值的比例，相当于权重，获得一次随机机会。如果中了，给奖励，没有就没有奖励了
	- 有保底奖励
- 整个活动有轮回概念。一次pk就是一轮，结束之后开启下一次pk
- pk场也分类型，不同类型不同配置，但是逻辑是相同的
- 获得积分明细，奖励明细
- pk可放弃，记录玩家当前状态
- 整场pk逻辑，也分为不同时期。
	- 空闲
	- 进入pk
	- 决战
	- 可领奖
- 积分逻辑
	- 完成任务-> 加积分
	- 积分卡 -> 加积分
	- 对方扔出炸弹 -> 减积分
