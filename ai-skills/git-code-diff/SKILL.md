# Git 代码差异分析与参数对比

## 核心方法论

当用户要求对比代码参数时，按以下步骤执行：

### 工作流程

1. 确定改造基准 - 找到改造前的代码版本
2. 获取改造前调用 - 查看所有改造前调用原函数的场景
3. 获取改造后调用 - 查看所有改造后调用新函数的场景
4. 逐参数对比 - 按顺序对比每个参数的值和来源
5. 检查新增参数 - 确认新增参数是否正确赋值
6. 输出对比报告 - 按规范格式输出结果

### 常用命令

```bash
# 查找合并提交（改造起点）
git log --oneline --all | grep -E "Merge|合并"

# 按作者查看提交
git log --author="name" --oneline -30 --name-only

# 查看特定提交的文件修改
git show commit-hash --stat

# 对比两个版本的差异
git diff commit1..commit2 -- filepath

# 查看改造前的代码
git show old-commit:filepath
```

## 参数对比核心原则

1. 找到所有调用点：列出改造前所有调用原函数的地方
2. 找到改造后的调用：列出改造后所有调用新函数的地方
3. 逐参数对比：按顺序对比每个参数的值和来源
4. 检查新增参数：确认新增参数是否正确赋值
5. 检查返回值：确认返回值是否正确处理
