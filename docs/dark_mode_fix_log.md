# MDX 词典深色模式适配日志

## 问题描述

在实现应用的深色模式（Dark Mode）时，发现词典查询结果界面的视觉体验极差，具体表现为：

1.  **背景割裂**：词典解释区域的背景色与全局背景色不一致，或者词典内容自带白色背景块，导致“像贴了一张白纸在黑底上”。
2.  **文字不可见**：
    *   许多 MDX 词典在制作时，为了在白纸上打印清晰，硬编码了纯黑色 (`#000000`) 或深蓝色 (`#0000FF`) 的文字颜色。
    *   当应用背景切换为深色（如 `#333333`）时，这些深色文字与背景对比度极低，几乎无法辨认。
3.  **视觉层级混乱**：原本用于强调的粗体、斜体或彩色文字，在深色背景下失去醒目效果，甚至比正文更难看清。

## 尝试过的方案与失败原因

### 第一次尝试：仅调整容器背景色
*   **操作**：将 `.result-content` 的背景色设为透明或深色。
*   **结果**：**失败**。虽然容器变黑了，但词典 HTML 内容中自带的 `background-color: white` 样式依然存在，导致文字依然显示在白色方块中，或者文字变成黑色浮在黑色背景上（完全看不见）。

### 第二次尝试：调整全局字体颜色
*   **操作**：设置 `.result-content { color: #cccccc; }`。
*   **结果**：**部分失败**。这只能改变那些没有内联样式的文字颜色。对于带有 `<font color="blue">` 或 `style="color: black"` 的内容无效，导致界面出现“黑一块白一块”的斑驳效果。

## 最终解决方案

采用 **CSS 深度选择器 (`:deep`) + 强制样式覆盖 (`!important`)** 的组合策略，对词典 HTML 进行“外科手术式”的样式重置。

### 1. 强制背景透明
彻底移除词典内容中所有元素的背景色，确保文字直接浮动在应用的深色背景之上。

```css
.result-content :deep(*) {
  background-color: transparent !important;
}
```

### 2. 智能颜色反转
针对词典中常见的语义标签，重新定义其在深色模式下的颜色。

*   **链接 (`a`)**：深蓝 -> 亮蓝 (`#58a6ff`)
*   **粗体 (`b`, `strong`)**：深黑 -> 纯白 (`#fff`)
*   **斜体 (`i`, `em`)**：黑色 -> 浅蓝 (`#a5d6ff`)

### 3. 硬编码颜色覆盖（关键）
使用 CSS 属性选择器精准定位那些硬编码了颜色的元素，并强制替换为适合深色背景的颜色。

```css
/* 修复硬编码的深蓝色（通常用于短语搭配） */
.result-content :deep(font[color="blue"]),
.result-content :deep(span[style*="color: blue"]),
.result-content :deep(span[style*="color:#0000FF"]) {
  color: #58a6ff !important; /* 改为亮蓝色 */
}

/* 修复硬编码的红色（通常用于错误提示或音标） */
.result-content :deep(font[color="red"]),
.result-content :deep(span[style*="color: red"]) {
  color: #ff7b72 !important; /* 改为柔和的亮红 */
}
```

## 效果对比

| 元素 | 原始 (Light) | 适配后 (Dark) |
| :--- | :--- | :--- |
| **背景** | 白色 / 浅灰 | 深灰 (#333333) |
| **正文** | 黑色 (#000) | 亮灰 (#e0e0e0) |
| **链接** | 深蓝 | 亮蓝 (#58a6ff) |
| **强调** | 黑色粗体 | 纯白粗体 |
| **蓝色文本** | 深蓝 (#0000FF) | 亮蓝 (#58a6ff) |

此方案实现了真正的“沉浸式”深色阅读体验，且无需修改 MDX 文件本身。
